==============================================================================
  E180-ZG120B HEX MODE TEST — On/Off & Color Control
  File: HEX_TEST_INSTRUCTIONS.txt
  Target end device: ESP32-C6 Super Mini + WS2812 on GPIO8, endpoint 0x0A (10)
  Coordinator config: stack_011_config.json (module_id=011, HEX native)
==============================================================================

OVERVIEW
--------
The E180-ZG120B in HEX mode uses binary frames over UART:
  [0x55][LEN][CMD_TYPE][CMD_CODE][DATA...][XOR_CHECKSUM]
  - LEN = length of payload (CMD_TYPE + CMD_CODE + DATA)
  - XOR_CHECKSUM = CMD_TYPE ^ CMD_CODE ^ all DATA bytes

The gateway firmware (stack_011_config.json) builds frames automatically
from the 3-byte template "55 CMD_TYPE CMD_CODE" stored in each function.
You send function-name commands; the gateway sends the binary frame.

Via the DA2 gateway ThingsBoard/CFML protocol:
  CFML:CFZB:<slot>:<FUNCTION_NAME>[:<args>]
  e.g.  CFML:CFZB:1:MODULE_GET_INFO


==============================================================================
PART 1 — COORDINATOR SETUP (run once or after factory reset)
==============================================================================

STEP 1.1 — Query current status
--------------------------------
Function: MODULE_GET_INFO
Gateway sends: 55 01 00 00 00
               [0x55][LEN=1][CMD_TYPE=0x00][CMD_CODE=0x00][XOR=0x00]

Expected response payload:
  Byte 0: network_status  (0x00 = networked, 0xFF = not networked)
  Byte 1: device_type     (0x00 = Coordinator, 0x01 = Router, 0x02 = End Node)
  Bytes 2-9: MAC address  (8 bytes, little-endian)
  Byte 10: channel
  Bytes 11-12: PANID (LE)
  Bytes 13-14: short address (LE)
  Bytes 15-22: extended PANID
  Bytes 23-38: network key

→ Check device_type == 0x00.  If not:

STEP 1.2 — Set Coordinator type
---------------------------------
Function: MODULE_SET_DEVICE_TYPE  (append byte 0x00 = Coordinator)
Gateway sends: 55 02 00 05 00 07
               [0x55][LEN=2][0x00][0x05][device_type=0x00][XOR=0x05^0x00=0x07] -- wait!
Correct XOR: 0x00 ^ 0x05 ^ 0x00 = 0x05
Gateway sends: 55 02 00 05 00 05

Expected response: 55 02 00 05 00 05  with cmd_data[0] = 0x00 (success)

Then reset:
Function: MODULE_SW_RESET
  mode=0x00, PANID=0xFF 0xFF, channel=0x00
  XOR: 0x00 ^ 0x04 ^ 0x00 ^ 0xFF ^ 0xFF ^ 0x00 = 0x00 ^ 0x04 = 0x04
Gateway sends: 55 05 00 04 00 FF FF 00 04

Wait 2 seconds for reboot (async 0x80/0x00 NOTIFY_BOOT received).
Verify with MODULE_GET_INFO again.


==============================================================================
PART 2 — OPEN NETWORK & JOIN
==============================================================================

STEP 2.1 — Open network (permit join for 180 s)
-------------------------------------------------
Function: MODULE_START_NETWORK
  (CFG_OPEN_NET, no data needed — default mode 0)
  XOR: 0x00 ^ 0x02 = 0x02
Gateway sends: 55 01 00 02 02

Expected feedback response: 55 01 00 02 00 03  (status=0x00 valid)

Async notification received (within ~500 ms):
  55 80 02 01 <window_time> <XOR>
  window_time > 0 confirms network is open.

STEP 2.2 — Power on / reset the ESP32-C6 Super Mini
-----------------------------------------------------
Within 180 seconds, power on or press reset on the C6 board.
The C6 runs ZigbeeColorBulb_C6_SuperMini.ino and scans all channels.

Watch for async notification from E180 coordinator:
  0x80/0x03  NOTIFY_NODE_JOIN
  Frame: 55 80 03 <len> <MAC 8B> <short 2B> <parent 2B> <mode 1B> <XOR>

  Example: 55 80 03 0D AA BB CC DD EE FF 00 11  28 A5  00 00  00  <xor>
                      ↑── MAC ──────────────↑  ↑short↑ ↑par.↑

  Record the SHORT ADDRESS (2 bytes LE, e.g. A5 28 → short = 0x28A5).

STEP 2.3 — Auto-bind (find target)
------------------------------------
Function: MODULE_AUTO_FIND_TARGET
  (CFG_FIND_BIND 0x00/0x14, no data)
  XOR: 0x00 ^ 0x14 = 0x14
Gateway sends: 55 01 00 14 14

Expected feedback: 55 01 00 14 00 <status_xor>
Async notification 0x80/0x10 (NOTIFY_FIND_BIND):
  55 80 10 05 <short_L> <short_H> <ep> <cluster_L> <cluster_H> <XOR>
  Example:  55 80 10 05 28 A5 0A 08 FC <xor>
                          ↑short↑  ↑ep↑ ↑── cluster ─↑


==============================================================================
PART 3 — ZCL CONTROL COMMANDS
(Replace <short_L> <short_H> with the 2 bytes from STEP 2.2)
(All ZCL frames use: cmd_type=0x02, cmd_code=0x0F)
The 11-byte ZCL header: [tx_mode=00][short_L][short_H][ep=0A][seq][dir=00][cl_L][cl_H][mn_L=00][mn_H=00][resp=00]
==============================================================================

FORMAT NOTE
-----------
Function: MODULE_ZCL_SEND_CONTROL_CMD
  Prefix = "55 02 0F"
  Appended data (is_prefix=true):
    [tx_mode=00] [short_L] [short_H] [ep=0A] [seq=01] [dir=00]
    [cluster_L] [cluster_H] [manu_L=00] [manu_H=00] [resp=00]
    [ZCL_CMD_ID] [ZCL_CMD_PARAMS...]
  + XOR checksum

The firmware computes LEN and XOR automatically.


---- ON/OFF CLUSTER (0x0006) ----

TURN ON (cmd_id=0x01)
---------------------
  Data: [00][<short_L>][<short_H>][0A][01][00][06][00][00][00][00][01]
  Full frame example (short=0x28A5):
    55 0D 02 0F 00 A5 28 0A 01 00 06 00 00 00 00 01 <XOR>
    LEN=0x0D=13, XOR=0x02^0x0F^00^A5^28^0A^01^00^06^00^00^00^00^01

CFML command: CFML:CFZB:1:MODULE_ZCL_SEND_CONTROL_CMD:28A5,0A,0006,01

TURN OFF (cmd_id=0x00)
----------------------
  CFML command: CFML:CFZB:1:MODULE_ZCL_SEND_CONTROL_CMD:28A5,0A,0006,00

TOGGLE (cmd_id=0x02)
--------------------
  CFML command: CFML:CFZB:1:MODULE_ZCL_SEND_CONTROL_CMD:28A5,0A,0006,02


---- LEVEL CLUSTER (0x0008) — cmd 0x04 MoveToLevelOnOff ----

Parameters: [level_uint8] [transition_time_L] [transition_time_H]
  transition_time in 100ms units. 0x000A = 1 second.

BRIGHTNESS 100% (level=0xFE)
-----------------------------

BRIGHTNESS 50% (level=0x7F)

BRIGHTNESS OFF (level=0x00)

  CFML command: CFML:CFZB:1:MODULE_ZCL_SEND_CONTROL_CMD:28A5,0A,0008,04,00,0A,00


---- COLOR CLUSTER (0x0300) — cmd 0x07 MoveToColor (XY) ----

Parameters: [X_L][X_H][Y_L][Y_H][transition_time_L][transition_time_H]
  X and Y are CIE 1931 chromaticity, 16-bit (0–65535, little-endian).

Color reference table:
  Color   X(hex16 LE)  Y(hex16 LE)  Description
  ------  -----------  -----------  -----------
  Red     B3 74        32 78        Warm red (sRGB → CIE wide gamut)

  Blue    14 CC        0A 55        Pure blue
  White   4C 2F        51 29        D65 white point
  Warm W  58 3B        41 26        Warm white (3000K)
  Cyan    1A 66        6C B0        Cyan
  Yellow  B5 5B        98 5D        Yellow
  Purple  7E 38        1C 3D        Purple/violet

==============================================================================
PART 5 — ASYNC EVENT REFERENCE
==============================================================================

All async events start with 55 [LEN] [cmd_type=0x80..0x82] [cmd_code] ...
The gateway listener task captures them and sends: CFZB:<slot>:EVT:<hex_bytes>

  55 80 00 ...  NOTIFY_BOOT         — module booted/reset
  55 80 01 ...  NOTIFY_NET_STATUS   — network joined/left
  55 80 02 ...  NOTIFY_NET_OPEN     — join window opened/closed
  55 80 03 ...  NOTIFY_NODE_JOIN    — end device joined (has MAC + short addr)
  55 80 05 ...  NOTIFY_DEVICE_JOIN  — device info (port/cluster table)
  55 80 06 ...  NOTIFY_LEAVE        — end device left network
  55 80 10 ...  NOTIFY_FIND_BIND    — auto-bind target found
  55 82 0A ...  ZCL_REPORT_IND      — attribute active report from end device
  55 82 0B ...  ZCL_DEFAULT_RSP     — default response frame from device
  55 82 0F ...  ZCL_CMD_IND         — ZCL control command received
  55 8F 02 ...  ZCL_SEND_CNF        — send confirmation (delivery status)


==============================================================================
PART 6 — XOR CHECKSUM CALCULATION REFERENCE
==============================================================================

XOR = CMD_TYPE ^ CMD_CODE ^ all_DATA_bytes

Example: MODULE_SW_RESET (mode=0x00, panid=0xFFFF, channel=0x00)
  CMD_TYPE=0x00, CMD_CODE=0x04, DATA=[0x00, 0xFF, 0xFF, 0x00]
  XOR = 0x00 ^ 0x04 ^ 0x00 ^ 0xFF ^ 0xFF ^ 0x00 = 0x04
  Frame: 55 05 00 04 00 FF FF 00 04
         ↑  ↑LEN=5                ↑XOR

Python helper:
  data = [0x00, 0x04, 0x00, 0xFF, 0xFF, 0x00]
  xor = 0
  for b in data: xor ^= b
  frame = bytes([0x55, len(data)]) + bytes(data) + bytes([xor])
