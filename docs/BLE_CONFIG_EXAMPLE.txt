🔧 COMMAND BREAKDOWN:
------------------------------------------------------------------------------

Protocol Layers:
  CFML:           → WAN MCU forwards to LAN MCU
      CFBL:       → LAN MCU: BLE command
          JSON:   → Subtype: JSON config
              0:  → Stack ID (0 or 1)
                 {json} → Actual JSON config

Expected Response:
  - Success: "BR:JSON:OK"
  - Failure: "BR:JSON:FAIL"

⚠️  IMPORTANT NOTES:
------------------------------------------------------------------------------
1. NO SPACES in the command - minified JSON only
2. Escape sequences like \r\n are preserved in JSON strings
3. Stack ID must be 0 or 1
4. Total command length must be < 4096 bytes
5. BLE handler must be initialized BEFORE sending this config
