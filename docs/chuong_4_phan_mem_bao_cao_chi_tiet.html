4.4

Protocol handlers phia LAN va mo hinh xu ly gan nguon

Zigbee Handler

Thu nhan framing tu E180-ZG120B, boc tach payload ung dung, kiem tra hop le va chuan hoa ve khung noi bo.

LoRa Handler

Xu ly chuoi AT, response TX DONE va du lieu P2P o Wio-E5, tranh block do Time-on-Air cao.

BLE Handler

Ho tro ca AT-module va native/GATT. Xu ly event ket noi, scan, write/read va notify.

RS-485 Handler

Quan ly serial half-duplex, timeout, polling va framing cho thiet bi cong nghiep.

MCU WAN Handler

Gom batch 10 ms, dong goi Data Frame, nhan lenh downlink va ACK/NACK voi WAN-MCU.

Module Monitor Task

Slot detect, ping AT, doc Device ID, reload preset va khoi dong lai handler khi can.

1. Nhan du lieu thoDoc UART/BLE event/SPI tu module vat lyBuffer tho

3. Gan metadataGan nhan nguon, timestamp, handler id, loai su kienBan ghi noi bo
4. Chuan hoaChuyen sang dinh dang thong nhat de uplinkPayload noi bo

4.6

Co che Web Config, App Config va FOTA

App Config phu hop khi:
  • Gateway vua lap rap xong va can quet thong tin phien ban.
  • Can debug hoac trich xuat log nhanh bang cap.
  • Can nap preset JSON lon o moi truong chua co web.
Web Config Portal phu hop khi:
  • Can thao tac tren thiet bi da trien khai ma khong mo vo hay ket noi cong COM.
  • Can giao dien truc quan cho ky thuat vien van hanh.
  • Can API noi bo de giam sat trang thai va trigger FOTA.
