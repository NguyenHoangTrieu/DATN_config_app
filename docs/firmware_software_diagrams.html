1. Kiến trúc phân lớp (Layered Architecture)

Phần mềm được chia thành bốn tầng: Application → Middleware → BSP → Driver, độc lập giữa WAN-MCU và LAN-MCU.

⬆ WAN-MCU (DA2_esp) — Internet & Cloud
Application
  • Config Handler (WF/MQ/LT/IN/SV/HP/CP/FW)
  • Server Comm Handler (MQTT / HTTP / CoAP)
  • MCU LAN Handler (SPI Slave — inter-MCU)
  • Internet Comm Handler (WiFi / LTE / Ethernet)
  • Internet Monitor Handler
  • Data Comm Handler (USB/UART — PC App)
  • Web Config Handler (AP/STA Portal)
  • FOTA Handler (điều phối cập nhật dual-MCU)
  • HMI Task (màn hình TFT)
Middleware
  • FreeRTOS — Scheduler, Queue, Semaphore
  • ESP-IDF WiFi / LTE / Ethernet Stack
  • MQTT / HTTP / CoAP Stack
  • NVS (Non-Volatile Storage)
  • TLS / DTLS
BSP
  • QSPI Driver (inter-MCU SPI Slave)
  • UART / USB Driver (PC App)
  • W5500 Ethernet Driver
  • LTE Modem Driver (SIM7600 / A7600)
Driver
  • ESP32-S3 Hardware: GPIO, SPI, UART, USB, I2C, ADC
⬇ LAN-MCU (DA2_esp_LAN) — Local Networks
Application
  • MCU WAN Handler (SPI Master — inter-MCU)
  • Config Handler (module commands dispatcher)
  • Zigbee Handler Task (E180-ZG120B)
  • LoRa Handler Task (Wio-E5, P2P mode)
  • BLE Handler Task (GATT Central + Native)
  • RS-485 Handler (Modbus RTU)
  • FOTA LAN Handler (self-OTA via WAN AP)
  • Module Monitor Task (health check)
  • Benchmark (throughput measurement)
Middleware
  • FreeRTOS — Scheduler, Queue, Semaphore
  • Module Config Controller (JSON dispatcher)
  • JSON Config Parser (AT template engine)
  • Storage Handler (SD Card store-and-forward)
BSP
  • SPI Master Driver (inter-MCU)
  • Module UART / SPI / I2C / USB Driver
  • SD Card SDIO 4-bit Driver
  • RS-485 Transceiver Driver
Driver
  • ESP32-S3 Hardware: GPIO, SPI, UART, I2C, SDIO, USB

3. Luồng dữ liệu Uplink & Downlink

Luồng Uplink: Sensor → LAN-MCU → WAN-MCU → Cloud

sequenceDiagram participant S as Sensor Node
(Zigbee/LoRa/BLE) participant LAN as LAN-MCU participant WAN as WAN-MCU participant CLD as Cloud Server S->>LAN: Gửi dữ liệu (UART/SPI/BLE) LAN->>LAN: Validation + Parsing + Normalization LAN->>LAN: Đóng gói DT frame (Header + Handler ID + CRC) LAN->>WAN: Gửi DT frame qua SPI Master (10ms batch) WAN->>WAN: Kiểm tra CRC + Sequence Number alt CRC hợp lệ WAN-->>LAN: ACK (OK + Internet Status) WAN->>CLD: Publish MQTT / HTTP POST / CoAP PUT CLD-->>WAN: Server ACK else CRC lỗi WAN-->>LAN: NACK → LAN retry end

Luồng Downlink: Cloud → WAN-MCU → LAN-MCU → Sensor

sequenceDiagram participant CLD as Cloud Server participant WAN as WAN-MCU participant GPIO as GPIO Handshake Pin participant LAN as LAN-MCU participant S as Sensor/Actuator CLD->>WAN: RPC Command (MQTT/HTTP) WAN->>WAN: Phân tích payload, xác định Handler ID đích WAN->>WAN: Đóng gói CF frame → downlink queue WAN->>GPIO: Assert GPIO Handshake (LOW→HIGH) GPIO->>LAN: Rising edge interrupt (ISR) LAN->>WAN: Khởi tạo SPI session để đọc CF frame WAN-->>LAN: Gửi CF frame (Header CF + Handler ID + Command) LAN->>LAN: Kiểm tra CRC + Sequence Number alt Hợp lệ LAN-->>WAN: ACK OK LAN->>S: Dispatch lệnh đến handler giao thức S-->>LAN: Phản hồi trạng thái LAN->>WAN: Gửi kết quả qua DT frame WAN->>CLD: Forward kết quả lên Server else Lỗi LAN-->>WAN: NACK → WAN retry (tối đa 3 lần) end

7. Cơ chế FOTA Dual-MCU

Quy trình cập nhật firmware từ xa được thiết kế tuần tự: LAN-MCU cập nhật trước, sau đó mới đến WAN-MCU, đảm bảo luôn có MCU có thể điều phối và xử lý lỗi.

sequenceDiagram participant SVR as Cloud Server participant WAN as WAN-MCU participant AP as Wi-Fi AP (WAN) participant LAN as LAN-MCU SVR->>WAN: Lệnh FOTA (URL firmware LAN + WAN) WAN->>WAN: Đánh dấu FOTA mode WAN->>LAN: Forward URL firmware LAN qua SPI (CF frame) WAN->>AP: Kích hoạt Wi-Fi AP mode LAN->>AP: Kết nối Wi-Fi STA vào AP của WAN LAN->>LAN: Tải firmware LAN qua HTTPS LAN->>LAN: Kiểm tra SHA256 hash LAN->>LAN: Ghi vào partition OTA, khởi động lại LAN-->>WAN: Handshake "LAN FOTA DONE" WAN->>WAN: Tải firmware WAN qua HTTPS WAN->>WAN: Kiểm tra hash, ghi flash, khởi động lại WAN->>SVR: Báo cáo FOTA status (OK/FAIL + version mới)
BướcThành phầnHành độngKênh
1ServerGửi lệnh FOTA kèm URL firmware LAN và WANMQTT / HTTP
2WAN-MCUPhân tích lệnh; đánh dấu FOTA mode—
3WAN-MCUForward URL firmware LAN xuống LAN qua SPI CF frameSPI
4WAN-MCUKích hoạt Wi-Fi AP mode (cung cấp Internet cho LAN)Wi-Fi AP
5LAN-MCUKết nối vào Wi-Fi AP của WANWi-Fi STA
6–7LAN-MCUTải firmware HTTPS, kiểm tra hash, ghi OTA partitionHTTPS
8LAN-MCUKhởi động lại; gửi handshake "LAN FOTA DONE" lên WANSPI
9–10WAN-MCUTải firmware WAN qua HTTPS, kiểm tra hash, ghi flashHTTPS
11WAN-MCUKhởi động lại; gửi FOTA status (OK/FAIL + version) lên ServerMQTT / HTTP
